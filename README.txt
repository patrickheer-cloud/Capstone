    Django CRM System - Customer Relationship Manager
═══════════════════════════════════════════════════════════

SYSTEM REQUIREMENTS:
--------------------
- Windows 7 or later
- Python 3.9 or later (with "Add to PATH" enabled)
- Internet connection (for initial setup only)
- Web browser (Chrome, Firefox, Edge, etc.)


INSTALLATION (First Time Setup):
---------------------------------
1. Make sure Python is installed on your computer
   → Download from: https://www.python.org/downloads/
   → IMPORTANT: Check "Add Python to PATH" during install

2. Double-click: INSTALL.bat
   → Wait for installation to complete (may take 2-3 minutes)

3. Double-click: CREATE_ADMIN.bat
   → Create an admin account when prompted

4. Installation complete!


RUNNING THE APPLICATION:
-------------------------
→ Double-click: START_CRM.bat

The application will:
  ✓ Start automatically
  ✓ Open in your web browser
  ✓ Be accessible at: http://127.0.0.1:8000
